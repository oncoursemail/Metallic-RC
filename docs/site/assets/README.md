# Metallic crow identity

`metallic-crow.webp` is the original crow mark created for Metallic on 2026-10-19. It replaces the old letter mark in the editable status page's header, hero, footer and favicon. The black mark has a transparent background; the small marks use a CSS filter for the dark surface. The hero keeps the original black artwork on warm ivory.

The asset is 1254 × 1254 pixels. A lossless WebP encoding preserves every RGBA pixel of the generated original while reducing its file size from 506,775 to 278,162 bytes. The same file is reused at each placement. Width and height attributes reserve layout space.

Created with the built-in image-generation tool. Art direction: a full-bodied, alert crow facing right; a clear beak, folded wing and long tail; near-black silhouette, restrained negative-space detail, crisp edges, transparent background, no lettering, shield, glow or mockup. This asset does not modify preserved game archives or compiled clients.
